# AURA — Documentación de reconocimiento (Fase 0)

**AURA** (Acompañamiento Universitario, Reflexión y Aprendizaje) acompaña a estudiantes durante su proyecto de grado:

- **AURA emocional**: categorías de emociones y situaciones con videos breves de acompañamiento.
- **AURA académica**: guías, ejemplos y ejercicios interactivos para construir el proyecto de grado.
- **Mi AURA**: avatar personal que comienza como una esfera difuminada y evoluciona con las experiencias y los aprendizajes. Nunca penaliza las emociones negativas ni las pausas.

Fecha del reconocimiento: 2026-11-20. Aún no se ha escrito código ni se ha eliminado ningún archivo.
